# ⚡ Hfd Pro Site

Backend ve masaüstü yazılım dillerine meraklı bir geliştirici tarafından sıfırdan geliştirilen modern, hızlı ve sade kişisel portfolyo platformu.

🌐 **Canlı Site:** [hfdprosite.netlify.app](https://hfdprosite.netlify.app)

---

## 🚀 Öne Çıkan Özellikler

* **Sıfır JavaScript (0 JS):** Hiçbir harici kütüphane veya framework kullanılmadan, yalnızca **Saf HTML5** ve **Saf CSS3** ile geliştirildi.
* **Işık Hızında Performans:** Minimum dosya boyutu ve sıfır betik yükü sayesinde hem masaüstünde hem de mobil cihazlarda anında açılır.
* **Dark Tema Estetiği:** Göz yormayan modern koyu tema renk paleti (`#0d1117` ve `#161b22`) ve akıcı CSS mikro animasyonları ile tasarlandı.
* **Tam Mobil Uyumluluk (Responsive):** Flexbox tabanlı esnek kart yapısı sayesinde tüm ekran boyutlarına otomatik uyum sağlar.
* **Sürekli Dağıtım (CI/CD):** GitHub `main` dalına yapılan her güncelleme, **Netlify** üzerinden saniyeler içinde otomatik olarak canlıya alınır.
* **Açık Kaynak Kod:** Kodlar [github.com/PyNetCoder/hfdprosite](https://github.com/PyNetCoder/hfdprosite) sayfasında şeffaf bir şekilde mevcuttur.
